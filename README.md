# Hearth & Herald documentation

Player documentation for the [Hearth & Herald](https://www.nexusmods.com/mountandblade2bannerlord/mods/11742)
Bannerlord mod, published at https://devoidaxis.github.io/hearth-herald-wiki/
with one frozen copy per mod release (the version picker in the site header).

- Content lives in `docs/` as plain Markdown (MkDocs Material).
- A release is published by running the "Publish docs version" workflow with
  the mod version; `latest` always tracks the newest release.
- Corrections welcome by pull request.
